# Support

Use [GitHub Issues](https://github.com/narcis2007/ultraclaude/issues) for reproducible bugs and
feature requests. Include the output of `ultraclaude preflight --pretty`, but remove usernames,
paths, session IDs, prompts, repository content, and authentication details first.

For security issues, follow [SECURITY.md](SECURITY.md) and report privately.

Account, billing, quota, and authentication issues belong to the provider of the user's Claude
Code or Codex account.
